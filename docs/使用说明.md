# 智能衣橱使用说明

版本：2.1.2  
应用名称：智能衣橱  
适用系统：Android 8.0（API 26）及以上

## 1. 软件简介

智能衣橱是一款结合本地衣橱管理、定位天气和 AI 穿搭推荐的 Android 应用。
用户可以拍照或从相册添加衣物，按类别管理衣橱，查看当天天气，并让大模型
根据天气、衣橱单品和已保存搭配生成穿搭建议。

主要功能包括：

- 首页天气、定位和生活提示
- 今日 AI 穿搭，一次生成多套方案
- 首次启动选择女性、男性或不限，AI 根据偏好调整搭配风格
- 自定义面试、约会、郊游等场景，空输入默认日常通勤
- 灵感焕新 / 经典套装两种推荐模式
- 衣橱增删改查、分类筛选和搜索
- 拍照、相册选图、图片压缩和私有目录保存
- 点击照片卡片选择拍照或相册、自由比例裁剪、四角与四边拖动、双指缩放
- 单品 AI 搭配
- 搭配库图文展示、衣物关联、删除和重复保存拦截
- API 配置、浅色/深色模式和本地数据库状态
- 旧衣物 AI 隐藏描述自动补全，升级后无需逐件重新保存

## 2. 安装与首次启动

### 2.1 安装

1. 将 `SmartWardrobe-v2.1.2-release.apk` 发送到 Android 手机。
2. 在手机文件管理器中点击 APK。
3. 如果系统提示，请允许“安装未知应用”。
4. 安装完成后打开“智能衣橱”。

如果手机中已有使用其他签名安装的旧版本，系统可能提示签名冲突。请先确认
是否需要保留旧数据，再决定是否卸载旧版本。使用同一 Release 签名的新版本
可以直接覆盖安装。

### 2.2 首次权限

应用可能申请以下权限：

- 定位：用于获取当前城市和天气
- 相机：用于拍摄衣物照片
- 相册/图片：用于选择衣物照片

拒绝定位权限时，应用会使用默认位置北京。拒绝相机权限时，仍可使用相册选图。
首次启动还会弹出“选择你的穿搭偏好”，可选择女性、男性或不限；该选项只
调整 AI 的版型、剪裁、配色和风格，不会改变衣橱中的可用衣物。

## 3. 配置天气与大模型

首次使用前，请点击首页右上角三个点，选择“设置”。

### 3.1 和风天气配置

填写以下两项：

- 和风天气 Host
- 和风天气 Key

Host 示例：

```text
https://your-weather-host/
```

Key 由和风天气控制台提供。Host 和 Key 必须同时填写，否则保存时会提示配置不完整。

### 3.2 大模型配置

填写以下三项：

- LLM Base URL
- LLM API Key
- LLM Model Name

Base URL 可以填写服务根地址，例如：

```text
https://api.deepseek.com
```

应用会自动拼接 `/chat/completions`；也可以直接填写完整的
`.../chat/completions` 地址。

Model Name 示例：

```text
deepseek-chat
```

所有配置只保存在本机 SharedPreferences 中，应用源码不包含真实 API Key。

### 3.3 保存与清空

- 点击“保存配置”后立即生效。
- 点击“清空配置”会删除本机保存的天气和大模型配置。
- 未配置对应服务时，天气或 AI 请求会被拦截并给出 Toast 提示。

## 4. 首页使用

### 4.1 天气卡片

首页顶部显示：

- 当前定位到的省市/区县
- 当天最低温 ~ 最高温
- 天气现象
- 天气刷新按钮

天气数据会缓存 30 分钟，避免频繁消耗 API 额度。没有网络时点击刷新，
应用会提示“网络未连接”，不会发出无效请求。

### 4.2 天气提示

天气卡片下方会根据天气显示生活提示，例如：

- 雨雪天气提醒带伞
- 高温晴天提醒防晒
- 大风、雾霾、沙尘提醒减少户外活动
- 天气适宜时显示适合出门

### 4.3 今日 AI 穿搭

首页 AI 卡片支持两种模式：

- ✨ 灵感焕新：优先从单品清单中自由组合新搭配
- 📁 经典套装：优先复用搭配库中已经保存的套装

操作步骤：

1. 确认衣橱中至少有一件衣物。
2. 确认已经配置大模型。
3. 选择推荐模式。
4. 输入框每次进入首页都显示灰色“日常通勤”占位，可直接输入“去面试”
   “周末约会”“郊游”等场景。
5. 点击“按场景生成穿搭”，也可以按键盘回车提交。
6. 输入框为空或只有空格时，系统自动使用“日常通勤”，不会恢复上次输入。
7. 生成后会按方案展示衣物图片、推荐理由和保存按钮。

不同场景会改变 AI 的搭配风格：面试更正式稳重，约会更精致甜美，郊游更休闲
舒适。点击卡片右上角刷新按钮，会在当前场景下重新生成一批方案。

生成结果说明：

- “经典套装推荐”表示方案优先复用了搭配库中的套装
- “全新灵感搭配”表示方案由当前单品重新组合
- 经典方案会显示“经典来源：套装名称”
- 图片匹配不到时会显示默认占位图，不会导致崩溃
- AI 返回少于 3 套方案时会按实际数量展示
- 如果衣橱无法组合出合理穿搭，会显示“当前衣橱暂无适合该天气的搭配”

点击“保存这套”可以保存单套方案，而不是把多套方案合并保存。

当天生成结果按“日期 + 推荐模式 + 场景 + 性别偏好”分别缓存。默认“日常通勤”
使用“默认”缓存键；输入“约会”时使用包含该场景的缓存键。切换性别后会读取
新性别对应的缓存或重新生成，不会继续显示旧性别风格的结果。跨天后自动失效。

## 5. 衣橱管理

### 5.1 添加衣物

1. 进入“衣橱”。
2. 点击右下角悬浮按钮。
3. 点击照片卡片，在弹窗中选择“拍照”或“从相册选择”。
4. 在裁剪页拖动四角或上下左右四条边构图，支持双指捏合缩放；
   裁剪框不会拖到图片外的黑边区域。底部保留“裁剪 / 旋转”控件。
5. 可点击“✨ AI 智能识别”，自动填写名称、类别和颜色；识别结果可以手动修改。
6. 检查衣物名称。
7. 选择类别：上装、下装、外套、裙装、鞋履、配饰。
8. 可填写颜色或风格、备注。
9. 点击“保存衣物”。

照片会在保存前压缩，最长边限制在 1600px，最终存放在应用私有目录。
数据库只保存文件名，不保存绝对路径。

AI 识别需要配置支持图片输入的 OpenAI Vision 兼容模型，例如 `deepseek-flash`。
未配置 Key、断网或模型不支持图片时，页面会给出提示，手动填写不受影响。

### 5.2 分类和搜索

衣橱顶部支持：

- 按类别筛选
- 按名称模糊搜索
- 按颜色/风格模糊搜索

搜索带有 300ms 防抖，停止输入后才会查询 SQLite，避免每输入一个字就立即查库。

### 5.3 查看、编辑和删除

点击衣橱卡片进入衣物详情页，可以：

- 查看大图、名称、类别、颜色和备注
- 编辑衣物信息
- 删除衣物

删除衣物时会同时删除应用私有目录中的图片，并从搭配关联表中级联移除关联。
删除前会弹出确认框。

## 6. 单品 AI 搭配

进入衣物详情页，点击“让 AI 帮我搭这件”：

1. 应用会获取天气，或使用已有天气缓存。
2. 将这件核心单品和其他衣物一起发送给大模型。
3. 结果以图文方案展示。
4. 每套方案可以单独保存到搭配库。

如果未配置大模型、没有网络或天气不可用，应用会直接提示，不会发起无效请求。

## 7. 搭配库

进入“搭配库”可以查看已保存的搭配。每张卡片包含：

- 搭配名称
- 来源（今日推荐 / 单品搭配）
- 保存日期
- 天气和温度快照
- 关联衣物横向图片
- 搭配正文摘要

点击卡片可以查看完整正文和关联衣物名称。

保存搭配时，应用会把衣物 ID 写入 `outfit_items` 关联表，因此搭配库可以直接
显示衣物图片，而不是只显示文字。

## 8. 数据迁移

换手机、换模拟器或打算卸载重装前，可以先用迁移包备份数据。迁移包只包含
衣橱、搭配和衣物图片，不包含 API Key 等本机配置。

### 8.1 导出数据

1. 进入首页右上角菜单 → 设置。
2. 下滑到“数据迁移”卡片。
3. 点击“导出数据”。
4. 在系统文件选择器中选择保存位置并确认。

导出成功后卡片会显示“已导出衣物 X 件、搭配 X 套、图片 X 张”，文件名形如
`SmartWardrobe-backup-20261107-142229.zip`。

### 8.2 导入数据

1. 把迁移包发送到新手机，保存到“下载”等容易找到的位置。
2. 在新手机安装同一签名的正式版，进入设置 → 数据迁移。
3. 点击“导入数据”，选择迁移包。
4. 在弹出的确认框中点击“确认导入”。
5. 等待校验和替换完成，应用会自动回到首页。

导入会覆盖本机现有的衣橱、搭配和图片。导入前应用会解压到缓存目录，校验
迁移包来源、格式版本、数据库结构和完整性；任何一步失败都会保留原有数据。

导入成功后建议重新填写和风天气与大模型配置，因为 API Key 不会随迁移包导出。

## 9. 设置与深色模式

设置页面提供：

- 穿搭偏好：女性 / 男性 / 不限
- 和风天气 Host / Key
- LLM Base URL / Key / Model Name
- 跟随系统 / 浅色模式 / 深色模式
- AI 衣物资料：一键补全旧衣物缺失的隐藏描述
- 数据迁移：导出数据 / 导入数据
- 本地数据库状态

切换主题后会立即重建页面并保存选择。深色模式下卡片、文字、输入框和按钮
均使用 Material 主题颜色，保证可读性。

旧版本保存的衣物可能没有 AI 隐藏描述。应用在首页拿到今日穿搭结果后会自动
串行补全缺失描述，不需要重新打开衣物编辑页；也可以在“设置 → AI 衣物资料”
查看缺失数量并点击“补全缺失描述”。补全只更新数据库中的隐藏字段，不会修改
衣物图片、名称或搭配记录。

## 10. 数据存储说明

应用使用原生 SQLite，数据库文件为 `wardrobe.db`。

主要数据表：

- `wardrobe_items`：衣物信息
- `outfits`：搭配正文、来源、天气和温度
- `outfit_items`：搭配与衣物的多对多关联

其他本地数据：

- SharedPreferences：API 配置、性别偏好、主题模式、AI 缓存
- 应用私有图片目录：衣物照片
- 天气内存缓存：30 分钟

应用不提供云同步功能。换机时请在旧设备导出 ZIP 迁移包，再在新设备的
“设置 → 数据迁移”中导入；迁移包不包含 API Key。

## 11. 常见问题

### 11.1 提示“请先配置天气 API”

进入右上角菜单 → 设置，填写和风天气 Host 和 Key，然后保存。

### 11.2 提示“请配置大模型 Key”

进入设置，完整填写 LLM Base URL、API Key 和 Model Name。

### 11.3 提示“网络未连接”

检查手机 Wi-Fi 或移动网络。断网时应用会直接拦截请求，不会进入长时间加载。

### 11.4 提示“AI 没有返回有效内容”

可能原因：

- 模型名称填写错误
- Base URL 不正确
- API Key 失效或额度不足
- 服务端限流

请检查设置，稍后点击右上角刷新重试。应用会忽略模型返回的
`reasoning_content`，只展示最终正文。

v1.4.1 已修复 `deepseek-flash` 的正常请求被误判为空正文的问题。原因是新版
DeepSeek 模型默认先输出 `reasoning_content`，思考 token 也计入
`max_tokens`；复杂衣橱 Prompt 会把输出额度全部耗尽，返回
`finish_reason=length` 且 `content` 为空。现在 DeepSeek 官方接口会自动
发送 `thinking: {"type":"disabled"}`，直接生成最终穿搭。

### 11.5 天气显示默认北京

通常是未授予定位权限或定位失败。可以在系统设置中重新授予定位权限，或保持
默认位置继续使用。

### 11.6 衣物图片显示占位图

可能是原图被删除、文件损坏或应用数据被清理。可以进入衣物详情重新编辑并
选择照片。

### 11.7 APK 无法覆盖安装

如果旧版本是 Android Studio Debug 包，签名与 Release 包不同，不能直接覆盖。
需要卸载旧包，或继续通过 Android Studio 安装 Debug 版本。卸载会清除本地数据。

### 11.8 换手机后如何保留衣橱

在旧手机进入设置 → 数据迁移 → 导出数据，把生成的 ZIP 发到新手机；在新手机
安装正式版后进入设置 → 数据迁移 → 导入数据。API 配置需要在新手机重新填写。

### 11.9 切换模型后提示 HTTP 400

大模型名称必须与服务商文档完全一致，区分大小写，且不能包含任何空格。
以下写法都会被接口判定为“模型不存在”：

- `DeepSeek-Flash`：大写字母不被接受
- `deepseek_flash`：下划线不是合法分隔符
- `deepseek-flash `：末尾多了空格
- 从网页复制时带入全角空格、不换行空格或零宽字符

DeepSeek 当前可用模型名为 `deepseek-flash` 和 `deepseek-v4-pro`；
`deepseek-chat` 目前仍会作为别名映射到新模型，但新配置建议直接填写
`deepseek-flash`。

v1.4.1 起，即使继续使用 `deepseek-chat` 或 `deepseek-flash`，应用也会
自动关闭思考过程，不需要用户手动修改请求参数。

从 v1.3.2 起，应用会自动清除模型名中的不可见字符，并在卡片中直接显示
服务端返回的具体原因。看到“模型名或接口配置有误”时，按提示检查
LLM Model Name 与 Base URL；看到“账户余额不足”则需前往服务商控制台充值。

## 12. 建议演示流程

答辩或演示时建议按以下顺序操作：

1. 打开设置，展示天气和大模型配置。
2. 添加 4~5 件衣物，包含上装、下装、外套和鞋履。
3. 保存 2 套搭配到搭配库。
4. 回到首页，选择“经典套装”，点击刷新。
5. 展示“经典套装推荐”和“经典来源”标签。
6. 保存其中一套，进入搭配库展示横向衣物图片。
7. 切换“灵感焕新”，再生成一批方案。
8. 打开飞行模式，点击刷新，展示断网 Toast 和按钮禁用。
9. 切换深色模式，展示主题适配。
10. 在 Database Inspector 中展示 `outfit_items` 的衣物 ID 关联。
11. 在设置 → 数据迁移中导出一份 ZIP，再导入同一份 ZIP，展示数据恢复。

## 13. 安全与注意事项

- 不要将 `keystore.properties` 和签名文件公开给他人。
- 不要把自己的 API Key 提交到公开仓库。
- 删除应用或清除应用数据会删除本地衣橱、搭配和图片。
- 覆盖安装前建议确认使用同一 Release 签名。
- 迁移包含有衣物照片，请勿随意发送给他人。
