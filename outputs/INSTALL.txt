智能衣橱 v2.1.6 - 安装与首次使用说明

安装要求
1. Android 8.0（API 26）或更高版本。
2. 日常使用请安装 SmartWardrobe-v2.1.6-release.apk；
   如需查看 AI 隐藏描述，请安装 SmartWardrobe-v2.1.6-beta.final.apk。
3. 在手机上打开 APK；如果系统提示，请允许“安装未知应用”。

首次使用
1. 打开 App，先选择穿搭偏好：女性、男性或不限。
2. 允许定位、相机和照片权限。
3. 进入“设置”，填写和风天气 Host/Key，以及大模型 Base URL、Key、
   Model Name，然后点击“保存配置”。
4. 返回首页刷新天气，并从“我的衣橱”开始添加衣物。

覆盖升级
- 正式版保持包名 com.example.wardrobe，并使用固定的 Release 签名。
- 已安装 v1.1 / v1.2 / v1.3.x / v1.4.x / v1.5.x / v1.6.x / v1.7.x / v2.0.0 / v2.1.x 正式版的手机可直接覆盖安装 v2.1.6，
  衣橱、搭配和图片会保留，无需卸载。
- v1.7.0 增加搭配删除与重复保存拦截，并修复裁剪范围和双指旋转问题。
- AI 识别需要配置支持图片输入的模型，例如 deepseek-flash。
- 裁剪框不会拖出图片范围，双指捏合可放大缩小图片。
- 旧版本衣物若没有 AI 隐藏描述，升级后会自动补全，无需重新保存衣物；
  也可在 设置 → AI 衣物资料 中手动补全。
- 版本号遵循 SemVer：新功能升 MINOR，兼容性修复升 PATCH，不兼容变更升 MAJOR。

数据迁移（换机）
1. 旧手机：设置 → 数据迁移 → 导出数据，保存生成的 ZIP。
2. 新手机：安装正式版，进入 设置 → 数据迁移 → 导入数据，选择该 ZIP。
3. 导入会覆盖本机现有数据，完成后需要重新填写 API 配置。
   迁移包包含衣橱、搭配和衣物图片，不包含 API Key。

其他说明
- Beta 包名 com.example.wardrobe.beta，可与正式版共存；两者数据相互独立。
- Beta 在衣物详情页额外显示“AI 隐藏描述（Beta）”，Release 不显示该区块。
- 安装包不包含真实 API Key，每位使用者需要填写自己的 API 配置。
- 如果手机中已有使用其他签名安装的旧版本，需要先备份并卸载，再安装本包。
