智能衣橱 v2.1.2 使用说明

一、安装
1. 将 SmartWardrobe-v2.1.2-release.apk 发送到 Android 手机。
   如需查看 AI 隐藏描述，可另外安装 SmartWardrobe-v2.1.2-beta.1.apk。
2. 点击 APK 安装，必要时允许“安装未知应用”。
3. 打开应用，按提示允许定位、相机和相册权限。
   拒绝定位时会使用默认位置北京；拒绝相机仍可从相册选图。
4. Beta 与 Release 包名不同，可以共存，但衣橱、搭配和 API 配置互不相通。

二、首次配置
首次启动先选择穿搭偏好：女性、男性或不限，之后可在设置中修改。
1. 点击首页右上角三个点，进入“设置”。
2. 填写和风天气 Host 和 Key。
3. 填写 LLM Base URL、LLM API Key、LLM Model Name。
4. 点击“保存配置”。

Base URL 示例：https://api.deepseek.com
Model Name 示例：deepseek-flash 或 deepseek-chat
应用会自动拼接 /chat/completions。
DeepSeek 官方接口会自动关闭思考模式，避免 reasoning_content 占用正文额度。

三、添加衣物
1. 进入“衣橱”，点击右下角悬浮按钮。
2. 选择拍照或从相册选择。
3. 填写名称，选择类别（上装、下装、外套、裙装、鞋履、配饰）。
4. 可填写颜色/风格和备注，点击“保存衣物”。
5. 已配置大模型时，应用会在后台为衣物生成一段 AI 隐藏描述。
   该描述只保存在数据库中，用于提升后续搭配的准确度。
   Release 不显示；Beta 可在衣物详情页查看。

四、今日 AI 穿搭
1. 首页选择“✨ 灵感焕新”或“📁 经典套装”。
2. 场景框显示灰色“日常通勤”，可直接输入“去面试”“周末约会”“郊游”。
3. 点击“按场景生成穿搭”，也可以按键盘回车提交。
4. 输入为空或只有空格时，应用自动使用“日常通勤”。
5. 等待生成后查看图文方案。
6. 点击“保存这套”可把单套方案保存到搭配库。

经典套装模式会优先推荐搭配库中适合当天天气的套装；
如果经典套装都不适合，会改为从单品重新组合。
当天结果按日期、推荐模式、场景和性别偏好缓存，默认场景使用“默认”缓存键。
每次进入首页场景框保持空白，不恢复上次输入。

五、单品 AI 搭配
1. 在衣橱中点击一件衣物进入详情。
2. 点击“让 AI 帮我搭这件”。
3. 查看图文方案并单独保存。

六、搭配库
搭配库卡片会显示关联衣物图片、天气、日期和搭配正文。
点击卡片可查看完整内容。

七、设置与主题
设置页支持跟随系统、浅色模式和深色模式。
设置页也可以修改穿搭偏好：女性、男性或不限。
“AI 衣物资料”可查看旧衣物缺失隐藏描述的数量，并一键补全；
首页也会在拿到今日穿搭结果后自动补全，不需要重新保存衣物。
“清空配置”会删除本机保存的天气和大模型配置。

八、数据迁移（换机备份）
1. 旧手机：首页右上角 → 设置 → 数据迁移 → 导出数据，
   把生成的 SmartWardrobe-backup-*.zip 保存或发送到新手机。
2. 新手机：安装正式版后进入 设置 → 数据迁移 → 导入数据，
   选择该 ZIP，并在确认框中点击“确认导入”。
3. 导入会覆盖本机现有衣橱、搭配和图片，完成后再填写 API 配置。
   迁移包不包含 API Key，导入完成后需重新配置天气和大模型。

九、常见提示
1. “请先配置天气 API”：到设置填写和风天气 Host/Key。
2. “请配置大模型 Key”：到设置填写 LLM 三项配置。
3. “网络未连接”：检查 Wi-Fi 或移动网络。
4. “AI 没有返回有效内容”：检查模型名称、Base URL、Key、额度或限流；
   升级到 v1.4.1 后已修复 deepseek-flash 思考过程吃满输出额度的问题。
5. 图片显示占位图：原图可能被删除，可重新编辑衣物并选择照片。

十、注意事项
- 应用源码不包含真实 API Key，配置只保存在本机。
- 删除应用或清除应用数据会删除本地衣橱、搭配和照片。
- 如果旧版本是 Android Studio Debug 包，因签名不同不能直接覆盖 Release 包。
- 从 v1.1 / v1.2 / v1.3.x / v1.4.x / v1.5.x / v1.6.x / v1.7.x 正式版覆盖安装到 v1.7.2 时，衣橱和搭配数据保留。
- 版本号遵循 SemVer：新功能升 MINOR，兼容性修复升 PATCH，不兼容变更升 MAJOR。
- 每次更新同时提供 Beta 与 Release 两个安装包。
